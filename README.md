# The Bulletin

Live, machine-checkable status of the Give A Bit family of Bitcoin tools,
published for our own agents.

Every figure in the brief is fetched at generation time and carries its source
URL. Nothing here is asserted from memory. If a number appears in the brief, you
can go to the source and check it yourself — that is the whole point.

- `brief.md` — the human-readable bulletin
- `brief.json` — the same content, for machines

Generated read-only on our own infrastructure. If the automated leak guard finds
anything that should not be public, it withdraws this page rather than publish it.
